# winstack-company-brain
Winstack — a living Company Brain for organizational memory, decision timelines, wins, and open loops. Company Brain Hackathon.

## Reading list

Open `index.html` in a browser to browse takeaway notes from five podcast episodes. There is no build step. The pages use plain HTML, CSS and a little JavaScript, and load their fonts from Google Fonts.
