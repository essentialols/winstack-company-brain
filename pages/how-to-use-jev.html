How to Use Jev

How I AI · Claire Vo · Jev, TypeSafe AI's decision model

26 ways to put Jev to work on your own data

This solo episode is a fast tour of Jev, a new model that returns decisions instead of text. Host Claire Vo, who also builds ChatPRD, walks through six things she built with it. Her thesis: cheap, fast classification makes data work practical, especially when Jev is paired with smarter models.

1 Reach for Jev when you need a decision, not text. Jev reads text and returns a value you defined in advance. It does not write. Use it wherever your code branches on a judgment call. Details · comparison table · timestamp

A smart if statement you can call at scale

Watch at 2:49

Text in, typed value out. Standard LLMs return generated strings. Jev selects from predefined values, such as this or that, yes or no, or 1 through 10. Claire calls it a decision model for that reason.

Where it fits. She names three jobs: smart branching, data classification and real-time loops. Think of routing a good result to one person and a bad one to support.

Where it doesn't. Chatbots and code generation still belong to standard LLMs. Jev takes text only, so an image needs a text description first.

Standard LLMJev
InputTextText; images only as descriptions
OutputGenerated textPredefined typed value
PricePennies to tens or hundreds of dollars per million output tokensAbout 4¢ per million input tokens, no output charge
Best atChat, code, anything generatedDecisions, classification, real time
What to do with thisList the judgment calls in one workflow that a person or a large LLM handles today. Test the highest-volume one first.

4 Run the same analysis on your own coding sessions. Claude Code and Codex store sessions on your machine. You can categorize that history without a big repo. Claire's shows how much her work has changed this year. Details · timestamp

A cheap mirror on how you actually work

Watch at 11:12

The data is already there. She started a Codex thread to run the analysis over her local sessions. She suggests this for anyone who codes, and says it costs next to nothing.

5 Triage with Jev first, then hand what's left to an LLM. Jev is a fast filter. A smarter agent then spends its effort only where it matters. Claire's Gmail test is the simplest version of this. Details · quote · timestamp

The filter-then-act pattern

Watch at 13:00

The Gmail test. Jev scored whether each email could be deleted, from its subject line and snippet. Clean tags came back, and another model worked through the groups. She kept the screen private.

"Jev alone is okay. Jev with an LLM buddy is super powerful."
— Claire Vo

The general shape. Tag, categorize, cluster or filter a large corpus with Jev. Then run precise AI actions on the right cluster.

  • Bugs: pull out the high-severity ones and triage them deeply.
  • Email: delete the obvious ones and work the rest with an agent.
What to do with thisStart with tags only. Review a sample before you let any score trigger a deletion or another action you can't undo.

8 Batch, score and promote to get instant search. Jev doesn't scan thousands of items instantly just by being in the middle. Claire's live comment search needs some architecture, and she says so plainly. Details · steps · timestamp

The architecture behind the fast demo

Watch at 21:00

What it does. Type a topic like screen share or slop. Matching comments come back quickly from the full set of about 4,400.

  1. Split the corpus into batches.
  2. Score each batch against the query.
  3. Push the high scores up as they arrive.

Why she shows it live. She is pushing back on 30-second viral demos that hide how the effect is built. Seeing the real latency is part of the lesson.

What to do with thisTime a single batch before you design the interface. That number sets how many items you can search while someone waits.

13 Give the classifier somewhere to put unclear items. Claire's session breakdown has a bucket for work that couldn't be categorized. Her comment dashboard also has a mixed sentiment group. Details · timestamp

An honest other pile

Watch at 12:00

Why it matters. Jev picks from the options you provide. Without an unclear option, weak matches have to land in a real category and distort the shares. This reasoning is this summary's, since she only shows the buckets.

Use it as a diagnostic. A growing unclear bucket is a sign that your categories no longer fit the data.

What to do with thisAdd an unclear option to your next choice question. Read that bucket first, because it shows which categories are missing.
14 Rank a list by scoring every option. Asking for one answer isn't the only way to choose. Claire scores each hex color and each quote against the input, then takes the top result. Details · timestamp

Score, sort, take the top

Watch at 24:02

One pattern, three uses. Her voice app and her comment search both rest on this.

  • Colors: score a list of hex values against each phrase.
  • Quotes: score the returned quotes against her sentiment.
  • Comments: score batches against a query and push the best up.

The tradeoff. Every option scored is another call, so long lists cost more time and money. That matters most in a live loop.

What to do with thisTry this on a list you currently sort by hand, such as leads, bugs or candidate sources. Keep the scores so you can see the near misses.
15 Let Jev choose the parameters for your next API call. In the voice app, Jev picks from a set list of filters for the quote API. Its decision becomes a safe input to the next system. Details · timestamp

Free text in, valid parameter out

Watch at 24:02

How it works. Speech is messy, and an API accepts only certain values. Jev bridges the two by selecting from the values you allow.

Why typed output helps. The answer comes from your list, so there is no generated text to parse. Your code can pass it straight along. This inference is this summary's, based on how Jev's outputs work.

What to do with thisFind a place where someone types free text and a system needs a fixed value. Offer the allowed values as a Jev choice.

18 Extract the labels first, then assign everything with Jev. Jev can't invent categories, so something else has to produce them. In Claire's insights graph, labels are extracted first and Jev quickly sorts everything into them. Details · steps · timestamp

A two-pass way to sort unknown data

Watch at 15:01

  1. Extract a set of labels from the data.
  2. Have Jev assign every item to those labels.
  3. Give the resulting groups to a stronger model for analysis.

How this differs from idea 3. Clustering finds groups first and names them afterward. This approach names the labels first and then fills them.

What to do with thisUse clustering when you don't know the categories. Use label assignment when you need consistent labels across many sources.
